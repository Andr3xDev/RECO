## 📘 Course Overview

This repository documents the learning process of the Computer Networks course, focused on the TCP/IP network model and its layers. Each lab was designed with a specific objective to deepen the understanding of real-world networking through:

- **Hands-on software setup**: Installation and configuration of specialized tools and networking environments.
- **Research and documentation**: Exploring theoretical concepts to complement practical tasks.
- **Network traffic analysis**: Using Wireshark to inspect and interpret packet-level network communication.
- **Simulations**: Designing and testing network topologies with Cisco Packet Tracer to simulate behavior and troubleshoot connectivity.

## 🧪 Lab Summaries

### Lab 01: Base Platform Setup
- **Objective**: Install and configure Unix/Windows operating systems and get familiar with virtualization tools.
- **Resources**: Computers, internet, virtualization software, OS images, USB drives/external disks.

### Lab 02: OS Configuration, Shell & Network Support
- **Objective**: Continue OS installation, explore network tools, and learn OS administration via the Shell.
- **Resources**: Lab computers, internet, virtualization software, OS images, Packet Tracer, Wireshark.

### Lab 03: Base Platform & Application Layer Protocols
- **Objective**: Install DNS and NTP services with basic shell scripting.
- **Resources**: Computers, internet, virtualization software.

### Lab 04: Application Layer Protocols & Physical Layer
- **Objective**: Monitor application layer protocols and perform cable standards review and RJ-45 crimping.
- **Resources**: Computers, internet, patch panels, crimping tools, wire strippers, cable testers, network cables, connectors.

### Lab 05A: Databases & Network Protocols
- **Objective**: Continue base software setup and operate key network protocols.
- **Resources**: Computers, internet, virtualization software, Wireshark.

### Lab 05B: Cloud
- **Objective**: Install and configure web server software in a cloud environment.
- **Resources**: Computers, internet access.

### Lab 06: Application Layer, Base Platform & Network Layer
- **Objective**: Set up and configure basic software for web servers.
- **Resources**: Computers, internet access.

### Lab 07: Basic Infrastructure & Network Layer
- **Objective**: Learn about OS and network services, install network management tools, and configure routers with static routing.
- **Resources**: Computers, internet, virtualization software, Packet Tracer, Wireshark, routers, switches.

### Lab 08: Data Link & Application Layer
- **Objective**: Examine Ethernet/WiFi operation and interconnection devices, and continue deploying application layer services.
- **Resources**: Computers, virtualization software, internet, switches, Packet Tracer, Wireshark.

## 🛠️ Technologies Used

- **Wireshark** – Packet analysis and protocol inspection.
- **Cisco Packet Tracer** – Network simulation and device configuration.
- **VirtualBox / Hyper-V** – Operating system virtualization for practice environments.
- **Linux & Windows OS** – Installation, configuration, and network service setup.
- **Bash / Shell** – OS administration, scripting, and task automation.
- **Apache / Nginx** – Web server installation and configuration.
- **MariaDB / MySQL** – Basic database setup and integration with network services.
- **DNS / NTP / DHCP** – Configuration and deployment of key network services.
- **RJ-45 Crimping Tools** – Physical layer practices: cable standards and testing.
- **Cloud Services (e.g., Replit, IaaS Platforms)** – Web application hosting and server setup.
- **Ping, Traceroute, Netstat, Ifconfig** – Network diagnostics and interface analysis.
